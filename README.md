# Project Portfolio Dashboard

**Project ID:** SP-343

A web-based application designed to help organisations manage and monitor multiple projects from a centralised platform.

## Objectives

- Manage multiple projects.
- Monitor project progress and status.
- Track project deadlines.
- Record project budgets and expenditure.
- Display project statistics through a dashboard.

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- HTML
- CSS
- JavaScript
