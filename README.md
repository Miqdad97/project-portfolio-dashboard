# Project Portfolio Dashboard

- **Project ID:** SP-343
- **Developer:** Badiru Miqdad
- **Matric Number:** U23CS1044
- **Course:** Software Engineering (CSC 403), Individual Project
  
A web-based application that helps organisations manage and monitor multiple projects from a centralised platform.

## Objectives

- Manage multiple projects
- Monitor project progress and status
- Track project deadlines
- Record project budgets and expenditure
- Display project statistics through a dashboard

## Target Users

- **Administrators:** manage the system and oversee project records
- **Project Managers:** create, update and monitor assigned projects
- **Management:** view project summaries and overall performance

## Scope

The application will cover user authentication, project management, progress tracking, deadline monitoring, budget recording and dashboard visualisation. Advanced features such as real-time collaboration, automated financial transactions and complex resource allocation are excluded from the initial implementation.

## Technology Stack

- Python
- FastAPI
- PostgreSQL
- HTML, CSS and JavaScript
